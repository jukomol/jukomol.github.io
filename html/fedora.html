Fedora

Fedora operating system is an open-source operating system that is based on the Linux OS kernel architecture. A group of developers developed Fedora under the Fedora Project. Sponsored by Red Hat, it is designed as a secure general-purpose OS with tools for virus protection, system utilities, office productivity, and multimedia.

On 5th January I decided to shift from Windows 10 to Fedora. Reasons include:

  1. Good memory management
  2. User-friendly GNOME interface
  3. Strong security features
  4. Stability
  5. Active community
  6. Live-mode tools
  7. Improved internet speed
  8. Easy to tweak and configure
